"# tic-tac-toe-game" 

A simple Tic Tac Toe game built with HTML,Javascript and styled using TailwindCSS.


🚀 Features
-Playable two-player mode
-Visual UI using TailwindCSS
-Built with modern front-end tools (Vite + Tailwind)

📂 Project Setup
-npm install
-npm run dev
-npm run tailwind
